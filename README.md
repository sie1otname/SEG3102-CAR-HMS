# CAR-HMS — SEG 3102 — Livrable 1

## Contenu
- `Rapport_SEG3102_Livrable1_CAR_HMS.pdf` : document d’analyse.
- `src/main/kotlin/seg3102/carhms/domain` : 7 sous-domaines et leurs README.
- `src/main/kotlin/seg3102/carhms/application/usecases` : 9 interfaces Kotlin.
- `src/main/kotlin/seg3102/carhms/application/dtos/queries` : 9 DTO.
- `src/test/resources/contracts` : 9 contrats initiaux Cucumber.

## Important
Les interfaces sont des contrats de commande, pas des implémentations fonctionnelles.
Les fichiers `.feature` sont des scénarios initiaux : les step definitions et l’exécution automatisée
seront à ajouter au moment de l’implémentation des tests.

- Confirmer auprès de l’enseignant les ambiguïtés documentées dans le rapport.
- Déposer le contenu sur la branche `contracts` du dépôt de l’équipe si la consigne est applicable.
